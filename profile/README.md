# PT BARAKA SARANA TAMA – GitHub Organization

Selamat datang di GitHub Organization resmi milik **PT BARAKA SARANA TAMA**, perusahaan induk dari **Baraka Express**, salah satu penyedia jasa ekspedisi cargo terkemuka di Indonesia.

---

## 🏢 Tentang Baraka Express

**Baraka Express** adalah penyedia jasa ekspedisi cargo yang beroperasi di seluruh Indonesia. Berdiri di atas dasar integritas dan dedikasi, kami berkomitmen memberikan layanan pengiriman yang profesional, tepat waktu, dan terpercaya.

### PT. Baraka Sarana Tama

**Visi:**  
Menjadi perusahaan transportasi yang handal serta dapat memberikan nilai tambah sesuai dengan standar industri terbaik kepada pelanggan, mitra kerja, pemegang saham, dan karyawan.

**Misi:**
- Mengembangkan sistem operasional yang sistematis, efektif, efisien, dan tepat guna.
- Meningkatkan kualitas SDM melalui pelatihan-pelatihan yang sesuai dengan standar industri.
- Memberikan layanan yang bersih, transparan, dan profesional dalam setiap hubungan bisnis dan sosial.

## 📂 Struktur Repositori

Organisasi ini secara umum mengelompokkan repositori ke dalam kategori berikut:

- `frontend/` – Proyek berbasis antarmuka pengguna (mis: web, Next.js, Vue).
- `backend/` – API dan sistem backend (mis: Laravel, Express).
- `mobile/` – Aplikasi mobile (mis: React Native, Flutter).
- `desktop/` – Aplikasi desktop (mis: Electron, JavaFX).

> 📌 Struktur ini bersifat fleksibel dan dapat berubah mengikuti perkembangan organisasi.

### 🔧 Workflow & Konvensi
Berikut ini adalah pedoman kerja dan alur standar kolaborasi tim developer internal kami:

- **Branching Strategy:**  
  - `main`: branch utama yang selalu dalam kondisi stabil dan siap produksi  
  - `dev`: branch untuk pengembangan umum  
  - `feature/{nama-fitur}`: branch untuk fitur baru  
  - `bugfix/{nama-bug}`: branch untuk perbaikan bug

- **Code Review:**  
  Setiap perubahan pada branch `dev` harus melalui _Pull Request_ dan direview minimal oleh 1 rekan tim sebelum digabungkan ke branch utama.

- **Style Guide:**  
  Kami mengikuti gaya penulisan kode yang sesuai dengan standar framework masing-masing (PSR untuk PHP, ESLint untuk JavaScript, dll).

> 📌 File `CONTRIBUTING.md` akan segera disiapkan untuk pedoman yang lebih mendetail.
